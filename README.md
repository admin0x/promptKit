# PromptKit（豆包漫剧制作指令库）

面向 AI 漫剧 / 短剧制作的提示词库。点一下把提示词填进豆包输入框，**不自动发送**，确认后再回车。

---

## 能做三件事

- **填入** —— 把提示词写进豆包输入框，不发送
- **修改** —— 卡片原地变表单，改标题与内容，存本地
- **新增** —— 填标题、内容、选分类，加入任意分组

> 删除为两段式确认：第一次变红「确认」，再点一次才删，无时间限制。

---

## 内置 22 条提示词

### 漫剧制作流程（7 条 · 有序）

按制作顺序编号，从上往下走完即完整链路：

| 序号 | 提示词 | 说明 |
| :---: | :--- | :--- |
| 01 | 小说转剧本 | 改成第一人称短剧文案，开头 3 句设钩子 |
| 02 | 漫剧剧本生成 | 输出【镜号+画面+台词+音效+时长】的单集 30 秒剧本 |
| 03 | 角色道具场景提取 | 从全文提取角色档案、高频道具、无人纯场景 |
| 04 | 角色三视图 | 生成正面/侧面/背面 + 头部六视角 + 局部细节设定页 |
| 05 | 分镜脚本 · 10 秒 | 按 35-50 字拆分文案，时间轴 [0-3][3-6][6-8][8-10] 秒 |
| 06 | 分镜脚本 · 15 秒 | 同上，时间轴 [0-4][4-8][8-12][12-15] 秒 |
| 07 | 旁白提取 | 删除所有对话只留叙述，可直接复制到剪映朗读 |

> 05 与 06 是同一环节的两种时长，按需二选一。

### 角色形象库（15 条）

3D 古风真人形象提示词，直接用于生图：

- **男性 9 条** —— 暗黑极繁、妖冶薄纱、西装阴湿、银发银饰、少年桃花林、全身像、抹额仰拍、BJD 魔皇、侧颜杀
- **女性 6 条** —— 光点破碎感、落雪绝色、暗夜银发、清冷远景、小香风、九头身

标题含风格关键词，搜「古风」「暗黑」「银发」即可定位。

## 面板构成

| 区域 | 说明 |
| :--- | :--- |
| 顶部 | 标题与关闭 |
| 工具行 | 搜索框（标题命中优先）+ 新增按钮 |
| 分组标签 | 漫剧制作流程 / 角色形象库，带条数 |
| 卡片 | 序号块 + 标题 + 摘要，悬停看预览，右侧竖排三按钮 |
| 悬浮球 | 位于右侧，可与 doubaokit 同时安装不重叠 |

## 快捷键

| 按键 | 作用 |
| :--- | :--- |
| `Esc` | 收起下拉 → 取消编辑/新增 → 关闭面板 |
| `Ctrl / ⌘ + Enter` | 编辑或新增时保存 |

## 存储

- 数据存浏览器 `localStorage`，**重启、重装扩展都在**
- 清除网站数据、换浏览器、无痕模式会丢失，建议定期备份
- 控制台执行 `DoubaoPromptKit.reset()` 恢复内置提示词库

## 环境要求

Chrome 111 及以上（Chromium 111+ 内核的 Edge、Brave 等）。

> `content_scripts` 使用 `"world": "MAIN"` 注入页面主世界，该能力自 Chrome 111 起支持。

## 提示词占位符

部分提示词需补充内容后再发送：

- **分镜脚本** —— 需粘贴旁白 / 对话文案
- **剧本生成** —— 需提供人设与故事大纲
- **形象提示词** —— 可替换发色、服饰、场景等关键词

> 分镜脚本类长达 5000+ 字。若豆包输入框有字数上限导致截断，点「修改」复制所需段落分段使用。
